## 结构型模式

- [x] 适配器（材料平台：直接调用 → 转换职责拆分 → 统一接口 → Spring MVC HandlerAdapter）
- [x] 桥接（材料包抽象与输出渠道：分支组合 → 职责拆分 → 两个变化维度独立桥接）
- [x] 组合（催收材料目录树：类型分支递归 → 目录递归 → 统一节点递归）
- [x] 装饰器（催收材料清单：集中分支 → 职责拆分 → 组合装饰 → Spring 显式装配）
- [x] 外观（催收材料准备：调用方编排子系统 → 工作流整理 → 单一外观入口）
- [x] 享元（材料规则：重复创建 → 构建职责提取 → 共享享元与案件外在状态隔离）
- [x] 代理（案件分派：直接调用 → 静态代理 → JDK 动态代理 → Spring JDK/CGLIB 事务 → 简化事务框架）

## 行为型模式

- [x] 责任链（模拟外呼：集中检查 → 提取规则 → 节点传递与短路 → Servlet Filter）
- [x] 命令（运营暂停外呼/重新分案：同步分支 → GoF 命令与调用者 → 数据命令、Worker、Handler 异步处理）
- [ ] 解释器
- [x] 迭代器（待分案案件池：嵌套遍历 → 统一 Iterable → 自定义 Iterator 跨组遍历）
- [x] 中介者（催收外呼工作台：组件网状调用 → 抽取协调者 → 中介者接口集中协调）
- [x] 备忘录（和解草稿撤销：手工保存字段 → 快照对象 → 封装 Memento；补充命令撤销、工作台协调和生产版本历史边界）
- [x] 观察者（案件分派：直接通知 → 职责拆分 → 订阅广播 → Spring 同步事件；未包含 Outbox/MQ）
- [x] 状态（和解方案：集中判断 → 规则拆分 → 状态对象 → Boot/MyBatis/乐观锁/事务 Outbox）
- [x] 策略（支付渠道：条件分支 → 提取渠道实现 → 策略接口与注册表路由）
- [x] 模板方法（支付流程：重复实现 → 公共步骤 → 固定模板与钩子）
- [x] 访问者（诉讼材料树：节点承载操作 → Service 类型分支 → Visitor 双重分派统计与校验）
