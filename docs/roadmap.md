## 创建型模式

- [x] 工厂方法（直接创建 → 简单工厂 → 工厂方法）
- [x] 抽象工厂（支付与退款产品族：直接创建 → 独立工厂 → 统一产品族工厂）
- [x] 建造者（人工复核任务：长构造器 → setter → 不可变 Builder）
- [x] 原型（复核模板：共享列表 → 浅拷贝 → 深拷贝）
- [x] 单例（共享状态反例 → 同步懒加载 → Holder、DCL、枚举与 Spring 作用域）

### 工厂体系与框架补充

- [x] 注册式工厂（Spring 案件处理器：业务分支 → 显式注册 → 集合注入自动注册）
- [x] 工厂与 IOC（服务定位器 → 构造器注入 → FactoryBean、ObjectFactory 与生命周期）

上述两项是课程工厂体系的补充，不额外计作 GoF 模式。
后续新增场景统一为催收金融业务，已有支付与物流示例保持原样。
