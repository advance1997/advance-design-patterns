# v1-naive：代码流程图与时序图

本版本以单个 `NaivePromotionEngine.evaluate` 方法串联活动资格判断、优惠金额计算和互斥优惠券择优，作为模式重构前的对照基线。

## 代码流程图

```mermaid
flowchart TD
    A[NaivePromotionEngine.runScenarios 创建订单] --> B[NaivePromotionEngine.evaluate 创建三张优惠券]
    B --> C{evaluate：遍历当前优惠券}
    C --> D{evaluate：按 coupon.type 进入 if-else}
    D -->|VIP_FIXED| E{evaluate：VIP 且金额满 500?}
    D -->|VIP_PERCENT| F{evaluate：VIP 且金额满 500?}
    D -->|NEW_USER| G{evaluate：首单且满 500 或含电子产品?}
    E -->|符合| H[evaluate：计算固定优惠 20 元]
    E -->|不符合| I[evaluate：优惠金额为 0]
    F -->|符合| J[evaluate：计算 9 折并封顶 50 元]
    F -->|不符合| I
    G -->|符合| K[evaluate：计算 9 折并封顶 30 元]
    G -->|不符合| I
    H --> L{evaluate：符合资格且优惠高于当前最优?}
    I --> L
    J --> L
    K --> L
    L -->|是| M[evaluate：更新最优优惠券和优惠金额]
    L -->|否| N[evaluate：保留当前最优结果]
    M --> O{还有优惠券?}
    N --> O
    O -->|是| C
    O -->|否| P[NaivePromotionEngine.printResult 计算实付金额并打印结果]
```

## 代码时序图

```mermaid
sequenceDiagram
    participant App as NaivePromotionEngine.runScenarios
    participant Engine as NaivePromotionEngine.evaluate
    participant Order as OrderContext
    participant Branch as 优惠券类型分支
    participant Output as 控制台
    App->>Order: 创建订单及用户条件
    App->>Engine: NaivePromotionEngine.evaluate(order)
    Engine->>Engine: 创建三张优惠券
    loop 每一张优惠券
        Engine->>Order: 读取金额、VIP、首单、商品类别
        Engine->>Branch: evaluate 内按优惠券类型判断资格并计算优惠
        Branch-->>Engine: 返回资格与优惠金额
        Engine->>Output: 打印本券评估路径
        Engine->>Engine: 与当前最优优惠比较并更新
    end
    Engine->>Engine: 调用 printResult(order, bestCoupon, bestDiscount)
    Engine->>Output: printResult 打印最优券、优惠金额和实付金额
    Engine-->>App: 完成本订单评估
```

## 阅读提示

- 同一类型分支既知道活动资格，也知道优惠算法；新增活动容易继续扩大分支。
- 优惠券互斥并择优是引擎中的显式业务流程，不是某个计算分支自动提供的能力。
- v2 将规则解释、表达式结构复用、优惠算法分别拆开，便于对照职责变化。
