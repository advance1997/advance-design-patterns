# v2-refactor：独立 Service 与类型分支

## 代码流程图

```mermaid
flowchart TD
    A[VisitorRefactorTest.shouldRunSeparateServicesWithTypeBranches] --> B[createMaterialTree 构建目录树]
    B --> C[MaterialStatisticsService.collect(root, statistics)]
    C --> D{node instanceof MaterialFolder}
    D -->|是| E[addFolder 并递归 collect(child, statistics)]
    E --> C
    D -->|否| F{node instanceof PdfDocument}
    F -->|是| G[MaterialStatistics.addPdf]
    F -->|否| H{node instanceof AudioRecording}
    H -->|是| I[MaterialStatistics.addAudio]
    H -->|否| X[抛出不支持的节点类型异常]
    G --> J[测试打印统计结果]
    I --> J
    J --> K[MaterialValidationService.validate(root, issues)]
    K --> L{按 MaterialFolder/PdfDocument/AudioRecording 分支}
    L -->|目录| M[递归 validate 子节点]
    M --> K
    L -->|PDF| N[检查签名并记录问题]
    L -->|录音| O[检查可访问性并记录问题]
    N --> P[测试打印校验问题]
    O --> P
```

## 代码时序图

```mermaid
sequenceDiagram
    participant Test as VisitorRefactorTest
    participant StatsService as MaterialStatisticsService
    participant ValidationService as MaterialValidationService
    participant Root as MaterialFolder
    participant Pdf as PdfDocument
    participant Audio as AudioRecording
    participant Stats as MaterialStatistics
    participant Issues as 校验问题列表
    Test->>Test: createMaterialTree()
    Test->>StatsService: collect(root, statistics)
    StatsService->>Root: instanceof MaterialFolder
    StatsService->>Stats: addFolder()
    loop 目录下的每个子节点
        StatsService->>StatsService: collect(child, statistics)
        alt PdfDocument
            StatsService->>Pdf: getSize() / getName()
            StatsService->>Stats: addPdf(size)
        else AudioRecording
            StatsService->>Audio: getSize() / getName()
            StatsService->>Stats: addAudio(size)
        end
    end
    Test->>Test: 打印统计结果
    Test->>ValidationService: validate(root, issues)
    loop 目录下的每个子节点
        ValidationService->>ValidationService: instanceof 并递归 validate(child, issues)
        alt PDF 未满足签名要求
            ValidationService->>Issues: 追加 PDF 缺签问题
        else 录音不可访问
            ValidationService->>Issues: 追加录音不可访问问题
        end
    end
    Test->>Test: 打印校验问题
```

## 阅读提示

- `MaterialStatisticsService.collect` 与 `MaterialValidationService.validate` 各自维护节点类型判断。
- 操作已从元素移出，但新增一种节点仍要修改每个操作 Service。
