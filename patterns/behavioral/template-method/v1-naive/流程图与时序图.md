# 模板方法模式：v1-naive 流程图与时序图

本图对应版本说明：支付宝和微信各自复制校验、调用、成功、失败、完成流程；service/AlipayPayment、WechatPayment。

## 代码流程图

```mermaid
flowchart TD
    A[PaymentTest.testAlipaySuccess 测试入口]
    A --> B[AlipayPayment.pay 业务入口]
    C[AlipayPayment.invokeChannel]
    B --> C
    D[AlipayClient.pay]
    C --> D
    C --> B
    Z[返回测试用例并打印实际路径]
    B -. 调用完成 .-> Z
    C -. 调用完成 .-> Z
    D -. 调用完成 .-> Z
```

## 代码时序图

```mermaid
sequenceDiagram
    participant Test as PaymentTest
    participant Entry as AlipayPayment
    participant Output as 测试输出
    participant Part1 as AlipayClient
    Test->>Entry: pay()
    Entry->>Entry: invokeChannel()
    Entry-->>Entry: 返回处理结果
    Entry->>Part1: pay()
    Part1-->>Entry: 返回处理结果
    Entry->>Entry: pay()
    Entry-->>Entry: 返回处理结果
    Entry->>Output: 打印执行路径与期望结果
    Output-->>Test: 输出实际结果
    Entry-->>Test: 返回业务结果
```

## 阅读提示

- 先从 `PaymentTest.testAlipaySuccess()` 进入，再沿图中的真实类名和方法名阅读源码。
- 本版本的模式关注点：模板方法固定算法骨架，并将可变步骤交给子类实现。
- 条件分支与返回细节请结合图中方法源码和同目录测试用例观察。
