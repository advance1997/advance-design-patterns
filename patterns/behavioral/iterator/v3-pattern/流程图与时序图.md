# 迭代器模式：v3-pattern 流程图与时序图

本图对应版本说明：保留分组快照，由 `GroupedCaseIterator` 用 `groupIndex`、`caseIndex` 跨组遍历；遍历游标属于每个迭代器，空组由迭代器跳过，调用方不需要了解内部结构；不支持删除。

## 代码流程图


## 代码时序图

```mermaid
sequenceDiagram
    participant Test as AssignmentTest
    participant Entry as AssignmentService
    participant Output as 测试输出
    participant Part1 as GroupedCasePool

    Entry-->>Test: 返回业务结果
```
