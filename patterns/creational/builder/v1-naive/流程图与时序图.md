# 建造者模式：v1-naive 流程图与时序图

本图对应版本说明：七个位置参数的构造器；能校验合法性，但多个 int 参数容易弄错含义和顺序。

## 代码流程图

```mermaid
flowchart TD
    A[BuilderTest.testValidTask 测试入口]
    A --> B[CollectionTask.preview 业务入口]
    C[CollectionTask.validate]
    B --> C
    Z[返回测试用例并打印实际路径]
    B -. 调用完成 .-> Z
    C -. 调用完成 .-> Z
```

## 代码时序图

```mermaid
sequenceDiagram
    participant Test as BuilderTest
    participant Entry as CollectionTask
    participant Output as 测试输出
    Test->>Entry: preview()
    Entry->>Entry: validate()
    Entry-->>Entry: 返回处理结果
    Entry->>Output: 打印执行路径与期望结果
    Output-->>Test: 输出实际结果
    Entry-->>Test: 返回业务结果
```

## 阅读提示

- 先从 `BuilderTest.testValidTask()` 进入，再沿图中的真实类名和方法名阅读源码。
- 本版本的模式关注点：建造者分步骤配置复杂对象，并在构建时统一校验和形成对象。
- 条件分支与返回细节请结合图中方法源码和同目录测试用例观察。
