# 建造者：催收人工复核任务配置

## 来源与约定

依据《01-1｜设计模式专项》阶段 2 大纲，会话
`01a0ba95-6029-74e0-a6e2-c68184b4d5db`，
大纲回合 `01a0ba95-6670-7ed0-8d27-9b2279bc770d`。
按用户的新要求，将课程设计要点改编为催收金融业务；下述类名、数据和细节是
本仓库工程化补充，不宣称是课程原始案例。

所有案件编号、配置和流程均为虚构。只模拟人工复核，不发送短信、不外呼，
不查询真实客户资料、不决定信用待遇或采取法律行动。教学参数不代表真实监管规则。

采用 Java 8、普通类与直接方法调用。每个版本独立持有源码和测试，
不共享业务类，不依赖其他版本。Javadoc 使用作者 advance 和上海时区创建时间。
测试仅由 JUnit 发现和运行，上方标注期望，直接打印实际值，不使用断言或函数式回调。
预期异常打印类型和信息，未抛出则提示人工核查；绿色测试不等于输出已被自动证明正确。

课程对应“配置对象、不可变对象、构造合法性、Builder 与构造器和 setter 的边界”。

## 版本与阅读顺序

| 版本 | 实现 | 观察重点 |
| --- | --- | --- |
| v1-naive | 七个位置参数的构造器 | 能校验合法性，但多个 int 参数容易弄错含义和顺序 |
| v2-refactor | 无参构造 + setter | 含义直观，但对象可能暂时不完整，preview 才检查全部约束 |
| v3-pattern | 普通静态 Builder + 不可变任务 | build 时统一校验并复制快照，之后不能再改任务配置 |

包前缀为 `com.advance.patterns.creational.builder.v1/v2/v3`。
本例是 Effective Java 风格的配置 Builder，不刻意增加 Director 或分阶段接口；
没有复杂组装流程时，不需要为了类图引入更多类。

## 配置与约束

- 名称非空；逾期天数范围非负且下限不大于上限。
- 执行窗口在 0 至 24 小时内，开始早于结束；不支持跨午夜窗口。
- 教学批次范围 1 至 1000；案件列表非空，数量不超过批次，无空白和重复编号。
- 9 至 18 只是示例人工复核执行窗口，不代表真实客户触达的法定时段。
- preview 只显示教学配置，不创建定时任务或真实触达任务。

V1 在构造器校验；V2 在 preview 校验；V3 在 build 校验。
三个版本并不是“前两个不校验，最后一个才正确”：
Builder 解决参数表达与构造阶段完整性，不是唯一能保证合法性的方式。

V3 复制输入列表，读取时返回只读快照；复用 Builder 修改名称或列表，不影响已建任务。
Builder 本身可变、非线程安全。当前列表元素是不可变 String；
如果未来改为可变案件对象，仅复制列表不足以隔离对象内部状态。

默认值：逾期 1 至 30 天、窗口 9 至 18、批次 100；必须提供名称与案件列表。
均为学习数据，不是催收风控、信用评价或监管策略。

## 边界

- 参数很少时构造器更直接，单纯链式调用不自动意味着更好的设计。
- build 校验对象本地约束，不能替代数据库中的案件存在性、权限或并发状态验证。
- 工厂决定创建哪一类对象，Builder 组织同一类对象的构造参数。
- 不涉及真实调度、跨时区窗口、持久化或生产审批流程。

## 运行

设置 JAVA_HOME 为 JDK 1.8，在仓库根目录执行：

```bash
./mvnw -f patterns/creational/builder/pom.xml test
./mvnw -f patterns/creational/builder/v1-naive/pom.xml test
./mvnw -f patterns/creational/builder/v2-refactor/pom.xml test
./mvnw -f patterns/creational/builder/v3-pattern/pom.xml test
```

全项目回归：`./mvnw test`。每个叶子模块可独立运行，无需先安装其他版本。
请先阅读测试上方期望，再对照类名、方法名、结果及异常路径。
