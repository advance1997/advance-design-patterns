# 抽象工厂模式：v1-naive 流程图与时序图

本图对应版本说明：service/PaymentService；支付和退款各自分支并直接 new；服务依赖四个具体类。

```mermaid
flowchart TD
    A[PaymentFamilyTest.testAlipayFamily 测试入口]

    B --> OP1
```

## 代码时序图

```mermaid
sequenceDiagram
    participant Test as PaymentFamilyTest
    participant Entry as PaymentService
    participant Output as 测试输出
```

## 阅读提示

- 条件分支与返回细节请结合图中方法源码和同目录测试用例观察。
