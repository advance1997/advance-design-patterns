# 装饰器模式：v1-naive 流程图与时序图

本图对应版本说明：一个服务使用两个 boolean 分支拼装文本；增强职责和执行顺序都集中在服务中。

## 代码流程图

```mermaid
flowchart TD
    A[MaterialExportTest.exportPlain 测试入口]
    A --> B[MaterialExportService.export 业务入口]
    C[MaterialBundle.getCaseId]

    B --> D
    Z[返回测试用例并打印实际路径]
    B -. 调用完成 .-> Z
    C -. 调用完成 .-> Z
    D -. 调用完成 .-> Z
```

## 代码时序图

```mermaid
sequenceDiagram
    participant Test as MaterialExportTest
    participant Entry as MaterialExportService
    participant Output as 测试输出

    Test->>Entry: export()

```

## 阅读提示

- 先从 `MaterialExportTest.exportPlain()` 进入，再沿图中的真实类名和方法名阅读源码。
- 本版本的模式关注点：装饰器通过同接口包装组件，在不改变原组件类的情况下叠加职责。
- 条件分支与返回细节请结合图中方法源码和同目录测试用例观察。
